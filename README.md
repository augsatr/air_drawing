# Air Drawing AI

An AI-powered air drawing application built using Python, OpenCV, and hand gesture recognition. This project allows users to draw in the air using hand movements and converts gestures into digital drawings in real time.

## Features

* Real-time hand tracking
* Air drawing using finger gestures
* Multiple drawing colors
* Eraser functionality
* Smooth drawing experience
* OpenCV-based computer vision

## Technologies Used

* Python
* OpenCV
* NumPy
* MediaPipe

## How It Works

The system detects hand landmarks using a webcam and tracks finger movement. Users can draw virtually in the air without touching the screen.

## Installation

1. Clone the repository:

```bash
git clone https://github.com/augsatr/air_drawing.git
```

2. Open the project folder:

```bash
cd air_drawing
```

3. Install required libraries:

```bash
pip install opencv-python mediapipe numpy
```

4. Run the project:

```bash
python air_draw.py
```
